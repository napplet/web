# Docs development optimizer target

## Symptoms

Expected: the root development command starts the docs alongside the website. Actual: the docs process exits while prebundling Vue dependencies, reporting unsupported destructuring transforms for chrome87/edge88/es2020/firefox78/safari14. User supplied the complete error and Node 26.11.1. The original checkout was on main at 6c4dafd2 with unrelated package.json workspace metadata and generated directories; those changes remain untouched on a new fix branch based on current origin/main.

## Current Focus

- hypothesis: docs build/source targets are esnext, but optimizeDeps has its separate legacy default target.
- test: reproduce development prebundling, then add the optimizer target and verify browser hydration/search.
- next_action: shipped as a focused fix PR after successful local verification.

## Evidence

- Main's docs Vite config sets build.target and esbuild.target to esnext and omits optimizeDeps.esbuildOptions.target. The showcase branch already sets all three and its full website/docs dev runner starts successfully.
- User's log identifies the dependency prebundler, not production bundling. Production builds alone cannot prove this fixed.

## Resolution

Root cause: Vite's dependency optimizer has separate esbuild options. Setting the production build and source-transform targets does not override the optimizer's default browser target set. With the installed esbuild version, Vue dependency prebundling fails while lowering destructuring.

Fix: add `vite.optimizeDeps.esbuildOptions.target: esnext` beside the existing docs targets. Document the alignment in the development README. No dependency or protocol change.

Verification: reproduced the original failure before editing, using the actual VitePress dev process. After the patch, `pnpm --filter @napplet/docs dev` stays up at http://localhost:5174/docs/. A real Chromium visit hydrated Vue and returned 16 local search results for napplet, with zero page errors. Full `pnpm build` (12 tasks), `pnpm type-check` (19 tasks), and `pnpm -r test:unit` pass.
