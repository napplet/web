<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build process → NIP-46 relay | Signer requests traverse untrusted relays through an injected transport. |
| Signer response → build process | Remote pubkeys and signed authorization events must be authenticated before use. |
| Sensitive value → logger/error/export | Client key and connection material can leak through ordinary serialization paths. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

</threat_model>
