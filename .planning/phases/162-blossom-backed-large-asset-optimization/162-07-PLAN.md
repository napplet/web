<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Retained code/CSS → reference classifier | Arbitrary generated text and URL syntax enters parser-backed eligibility logic. |
| Signed private table → generated loader | Mapping fields select resource URIs and expected byte integrity. |
| Shell resource domain → browser consumer | Untrusted returned whole Blobs become responses or object URLs only after verification. |
| Object URL/cache → iframe lifetime | Large verified bytes remain live in browser memory until explicitly released. |
