<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rollup output → optimizer | Build filenames, bytes, MIME data, and reference shapes enter deterministic selection and rewrite logic. |
| Optimizer → upload service | Exact selected bytes and short-lived authorization cross into an external-service adapter seam. |
| Signed artifact → napplet runtime | Private mapping data drives resource retrieval inside an opaque-origin iframe. |
| Runtime resource API → consumer | A whole Blob returned by the shell crosses back into the napplet and must match signed metadata. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-162-01 | Tampering | Upload descriptor and private resource table | high | mitigate | Task 1 hashes exact emitted bytes, requires descriptor hash/size equality, serializes stable metadata, and tests digest substitution. |
| T-162-02 | Tampering | Destructive artifact and effective requirement commit | high | mitigate | Task 1 quarantines selected files, derives resource requirement only from committed count, verifies upload/rewrite/recovery, writes the aggregate hash last, and tests restoration/tag absence at every failure. |
| T-162-03 | Tampering | Runtime Blob substitution | high | mitigate | Task 1 validates whole-Blob length and SHA-256 against signed private metadata before exposing bytes to the consumer. |
| T-162-04 | Denial of Service | Candidate rendering and Blob verification | high | mitigate | Task 1 uses deterministic one-at-a-time rendering, bounded candidate sets from emitted output, and whole-Blob limits inherited from the selected asset policy; generated tests exercise bounded failure. |
| T-162-05 | Information Disclosure | Build logs and optimization report | medium | mitigate | Task 1 reports paths, hashes, counts, and status only; the service interface contains no long-lived signer secret and tests snapshots for stable redacted output. |
| T-162-06 | Elevation of Privilege | Private loader treated as protocol authority | medium | mitigate | Task 1 keeps mapping and loader fields out of NIP-5A metadata and shell messages; tests assert the existing resource methods are the sole runtime boundary. |
</threat_model>
