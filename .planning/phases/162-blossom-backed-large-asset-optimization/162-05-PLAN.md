<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public directory relays → discovery | Untrusted relay events claim the user's relay preferences. |
| User write relays → server-list discovery | Untrusted relays deliver authored kind-10063 server lists. |
| Server-list URL/DNS → build process | An authored or forged URL can target internal network resources or rebind across redirects. |
| Build process → Blossom HTTP | Exact private build bytes and signed authorization cross to external servers. |
| Blossom response → artifact transaction | A descriptor becomes evidence that deletion/rewrite may proceed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-162-20 | Spoofing | kind-10002/kind-10063 discovery | high | mitigate | Task 1 verifies signatures, authors, kinds, time bounds, and deterministic newest/tie selection at both relay stages. |
| T-162-21 | Tampering | read/write relay semantics and server order | high | mitigate | Task 1 excludes read-only relays, never treats kind-10002 URLs as servers, and tests normalized first-occurrence BUD-03 ordering. |
| T-162-22 | Elevation of Privilege | server URL SSRF and redirect rebinding | high | mitigate | Task 1 rejects unsafe URL forms and private/reserved DNS answers and re-resolves/revalidates every redirect hop. |
| T-162-23 | Elevation of Privilege | kind-24242 authorization | high | mitigate | Task 2 scopes short-lived signed authorization to upload and the expected hash and never forwards it to an unvalidated origin. |
| T-162-24 | Tampering | upload descriptor | high | mitigate | Task 2 verifies JSON bounds, lowercase digest, byte length, expected server, and signature-derived request context before accepting evidence. |
| T-162-25 | Denial of Service | relay, DNS, and HTTP clients | high | mitigate | Tasks 1–2 bound directory/relay/event/DNS/redirect/body/retry/concurrency counts, timeouts, and cancellation. |
| T-162-26 | Information Disclosure | URL/error/report output | medium | mitigate | Both tasks redact credentials, authorization, query material, response bodies, and signer data from typed errors and evidence. |
</threat_model>
