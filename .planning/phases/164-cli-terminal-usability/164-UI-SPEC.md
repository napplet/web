# CLI terminal design contract

Use a compact lowercase ASCII napplet wordmark and version above human-facing commands. Cyan identifies sections and progress, green indicates success, yellow indicates warnings or dry runs, red indicates failure, and dim text holds labels and secondary details. Every colored state also has text. No-color output retains the same information. Layout adapts to terminal width without truncating copyable event references. Display paths, selected deployment targets, signer type, relay and server destinations before publishing. Show actual completed operations and per-server results; never treat failed operations as success. Finish with a clear result and relevant next command. Prompts show defaults and allow correcting invalid input. Secrets remain hidden. JSON and version output contain no banner or ANSI sequences. Redirected output contains no cursor control. Visual proof must include startup/help, missing-field completion, live deployment progress and result, and non-interactive behavior.
