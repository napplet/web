# Add --proxy for HTTP and SOCKS5 proxies to the napplet CLI

Every CLI command that reaches Blossom servers or relays should accept a proxy. This is CLI transport configuration, not napplet protocol surface.

1. `packages/cli/src/network.ts`: validate `http`, `https`, `socks5` and `socks5h` proxy URLs, redact credentials, hold one `Deno.createHttpClient` proxy client, and expose a proxy-aware `fetch`, `WebSocket` constructor and nostr-tools relay pool.
2. Route the call sites: Blossom uploads (`blossom-upload.ts`), deploy publishing (`deploy-network.ts`), `init` suggestions (`suggestions.ts`), and the NIP-46 `RelayPool` with applesauce's per-connection NIP-11 lookup (`nostr-connect-pool.ts`).
3. `cli.ts`: read `--proxy` for `deploy`, `init` and `keys connect`, reject it elsewhere, configure before the command and close after. The deploy plan names the proxy.
4. Tests: validation, redaction and scoping, plus an end-to-end fixture through local HTTP and SOCKS5 proxies against proxy-only host names. Help, README and docs page. Changeset (minor).
5. Verify build, type-check, unit tests and the slop gate; commit by path on `feat/cli-proxy`, push, open the PR.
