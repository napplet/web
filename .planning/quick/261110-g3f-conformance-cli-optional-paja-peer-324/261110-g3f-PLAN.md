# Make @kehto/paja an optional peer of conformance-cli

Resolve napplet/web#324. conformance-cli pins core 0.40 / nap 0.39 but depends on Paja 0.21.x (peers core/nap <0.35). No Paja release accepts core 0.40 / nap 0.39 yet (newest 0.32.1 peers core 0.38 / nap 0.37), and Paja only backs local screenshot previews. The user chose to make it an optional peer.

## Tasks

1. Move `@kehto/paja` from `dependencies` to an optional `peerDependencies` entry and keep it as a devDependency for tests.
2. Load Paja through a dynamic import in `src/screenshot-preview.ts`. A missing module gives an install hint; other load errors are rethrown.
3. Unit-test both load paths.
4. Update the README and `apps/docs/packages/conformance-cli.md`, and add a minor changeset.
5. File the upstream Paja issue in kehto/web and link it.

## Verification

`pnpm build`, `pnpm type-check`, `pnpm -r test:unit`, aislop scan.
