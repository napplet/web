# Quick Task 260912-wr8: Restructure napplet skills for the skills.sh installer and fix design guidance

## Objective

Make the napplet agent skills installable with the open `skills` CLI (skills.sh), give every skill an intuitive `napplet-<skill>` name, split the content so each skill does one job without flooding context, fix the three recurring design failures (title headers, non-responsive layouts, website-shaped non-compact UI), remove the now-dead custom installer, and sync every doc that mentions skill installation.

## Decisions

- **Canonical location:** root `skills/<name>/SKILL.md` as real files (skills.sh discovers `skills/` at the repo root; the previous root entry was a symlink into `packages/skills/skills`).
- **Install command:** `npx skills add napplet/napplet` (all skills) / `--skill napplet-make` (one skill). No custom installer.
- **`@napplet/skills` package retired:** its only code was the installer, which skills.sh replaces. `napplet skills` CLI subcommand removed; `napplet guide` and boilerplate "Next" output point to skills.sh.
- **Skill map (8):** `napplet-make` (orchestrator), `napplet-design` (capability/boundary spec), `napplet-ui` (NEW — applet layout/visual contract), `napplet-build` (implementation workflow), `napplet-sdk` (NEW split — per-domain `@napplet/sdk` reference), `napplet-interop` (NEW split — INC/intent/archetype conventions), `napplet-port` (migration), `napplet-test` (verification).

## Tasks

### Task 1: Author the `napplet-*` skill set at `skills/`

**Files:** `skills/napplet-*/SKILL.md`, remove `packages/skills/`, root `skills` symlink replaced by a directory.

**Action:** Rewrite the five skills into eight focused ones with `name: napplet-<skill>` frontmatter. Deduplicate the INC/intent text into `napplet-interop`, the per-domain API into `napplet-sdk`, and put the compact / responsive-maximalist / no-title-header / min-size-notice rules into `napplet-ui`, cross-referenced from make, design, build, port, and test.

**Done:** Every skill has a unique `napplet-` name matching its directory, and the UI rules are stated once in `napplet-ui`.
