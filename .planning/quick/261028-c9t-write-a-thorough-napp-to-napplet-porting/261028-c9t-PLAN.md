# Porting NAPPs to napplets

Goal: ship a discoverable skill that guides an agent from an eskema/nostrapps NAPP source folder to a working napplet in one request, preserving product behavior and explicitly surfacing unsupported semantics.

1. Read the live NAPP document, current NIP-5D PR head and relevant NAP documents; distinguish source behavior, canonical target contracts, shipped SDK surface and runtime support.
2. Add `napplet-port-napp` with source inventory, semantic migration references, implementation workflow, parity scenarios and evidence-based completion criteria. Route the generic port/make skills and public agent-skills guide to it.
3. Validate skill structure, links and installation discovery; forward-test realistic source cases. Run skill contracts, repository build, type-check, recursive unit tests and the pinned AI-slop gate. Record actual results and any baseline limitations.
4. Commit only task files, push `docs/napp-port-skill`, open a PR and record verification in the GSD summary and state.

Protocol material in this change is non-normative authoring guidance. The living NIP-5D and NAP documents remain authoritative; no local protocol snapshot is introduced. Work runs inline through GSD quick in an isolated worktree; the original checkout's unrelated changes remain untouched.
