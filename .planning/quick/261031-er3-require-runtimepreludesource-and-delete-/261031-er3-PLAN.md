# Quick Task 261031-er3: Require runtimePreludeSource and delete the conformance fallback runtime fixture

## Why

`bootAndCollect` carries a hand-written "embedded compatibility fixture" that predates the `runtimePreludeSource` option (PR #261). It is a second, hand-maintained copy of three NAP bindings (RESOURCE, GAMEPAD, LLM) with its own request plumbing. Every NAP PR that touches conformance has been growing it and adding a sync test. No real host uses it: the CLI reads `@napplet/shim/prelude.global` and the web app imports it with `?raw`. The maintained shim installs domains from an explicit allowlist, which is the intended need-based model; the fixture contradicts that and the README paragraph exists only to document its deficiency.

## Tasks

### Task 1: Make the maintained prelude required in the engine
- `packages/conformance/src/run/boot.ts`: `runtimePreludeSource: string` on `BootOptions`; `runtimePrelude(domains, runtimePreludeSource)` only renders the IIFE + `install({ domains })` + installed probe; delete `FALLBACK_RUNTIME_*`, `GAMEPAD_STATE_TOOLS_SOURCE`, and the `LLM_PRELUDE_SOURCE` import; update the module header.
- Delete `packages/conformance/src/run/llm-prelude.ts`.
- `packages/conformance-cli/src/server.ts`: `runtimePreludeSource: string` on `BootConfig`.

### Task 2: Retire fixture tests, keep reference-shell coverage on the maintained shim
- Delete `packages/conformance/src/run/gamepad.test.ts` and `llm.test.ts` (they test the fixture and its sync with `@napplet/nap`).
- `boot.test.ts`: drop the fixture resource test; pass the maintained source to the DOM wiring tests.
- `bindings.test.ts`: make the prelude source required in the fixture helper; replace the "fallback runtime" case with a maintained-shim allowlist case; add GAMEPAD and LLM round-trips against the reference shell.

### Task 3: Docs and release metadata
- Remove the "embedded compatibility fixture" paragraph from `packages/conformance/README.md` and `apps/docs/packages/conformance.md`; fold the still-true `installedGlobal`/`bootError` and signature-verification notes into the `bootAndCollect` paragraph and state that the source is required.
- Changeset: `@napplet/conformance` minor (0.x breaking: required option).
