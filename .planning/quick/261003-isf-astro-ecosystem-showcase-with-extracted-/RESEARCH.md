# Implementation research (non-normative)

Inspected 2026-10-03. Canonical authority remains the living documents linked here. These notes describe this implementation, not protocol requirements.

- [NIP-5D](https://github.com/nostr-protocol/nips/pull/2303), head 24711d9: Transport, Identity, Manifest, Security Considerations. Current status open proposal. Read the actual 5D.md file, not the stale pull-request description.
- [NIP-5A](https://github.com/nostr-protocol/nips/blob/master/5A.md), Aggregate Hash: verified signed releases use the canonical sorted `hash path\n` byte input. The old copy of 5A.md in the 5D proposal branch lacks the current aggregate section; the living merged spec supplies it.
- [NAPs](https://github.com/napplet/naps): downstream NAP-SHELL mandatory-bootstrap framing differs from 5D's direct domain availability model. The new preview grants no domains, needs no handshake, and makes no universal assertion about NAP-SHELL.
- [napplet.soy source](https://github.com/zeSchlausKwab/napplet-soy): MIT loader `packages/runtime/src/index.ts` supplies the verify-before-injection, first CSP, frozen namespace and srcdoc pattern. Adapted locally with signed-manifest verification and pinned release IDs. Do not import its full shell host/prelude or make a shell.ready/init exchange a loading prerequisite for no-domain apps.
- Original signed app artifacts contain toolchain `napplet-type` and `napplet-config-schema` HTML metadata. These are not NIP-5D requirements, and this loader neither reads nor enforces them. Signed artifacts remain byte-identical. This is flagged as undocumented downstream surface rather than adopted as protocol.
- App provenance is in `apps/web/public/showcase/provenance.json`; events resolved directly from `wss://relay.napplet.soy`, original blobs from Blossom, source archives hash-verified, licenses MIT. Curated releases are cached static assets, with signature/path/aggregate verification at every launch. No relay or Blossom request is needed on the homepage or during quick play.
- Verified choices: Impossible Machine, Rail Game, Sketch Loop. All have zero required domains, run with the conservative CSP and an empty `window.napplet`, and degrade for absent save/account services. Their external shell links remain available.
- [Kehto](https://github.com/kehto/web) offers runtime/shell/services/ACL and Paja. Source explicitly labels the toolkit alpha; the showcase says early tooling and links to current docs rather than promising full compatibility.
- [Astro Svelte integration](https://docs.astro.build/en/guides/integrations-guide/svelte/) allows static rendering and client hydration of the existing Svelte 5 explainer. Homepage itself is Astro HTML. Astro 7 and its Vite 8 integration use the current compiler; the build targets ES2022. Legacy packages retain their compatible Vite 6 resolution.
- [GSAP matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/) disables and reverts movement for reduced-motion. Reveals never hide the static reading path. Illustrations explain composition, protocol layers, build stages and runtime components.
- Bunny: all five required secret names configured; latest inspected deploy run 34724295540 succeeded including upload/purge. Shared assembly now prevents link-check and production directory drift. Actual final deployment remains gated on the PR merge; readiness is verified against the same literal-file artifact.
